# CCNA Labs Repository
This repository contains hands-on labs based on Cisco CCNA preparatory courses, focused on reinforcing fundamental networking concepts through practical configuration and analysis.

## 📚 Covered Courses
CCNA: Introduction to Networks
CCNA: Switching, Routing, and Wireless Essentials
CCNA: Enterprise Networking, Security, and Automation

## 🎯 Purpose
To serve as study material, practice, and reference for students preparing for the CCNA (200-301) certification or anyone looking to strengthen their networking knowledge.

## ⚠️ Disclaimer
This is an educational repository and is not officially affiliated with Cisco. The labs are based on content from the Cisco Networking Academy courses.
